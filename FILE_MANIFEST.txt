QUICK START
===========

1. Initial Setup:
   $ bash scripts/setup.sh

2. Access Services:
   - API: http://localhost:8000
   - Docs: http://localhost:8000/docs
   - Dashboard: http://localhost:3000

3. Test APIs:
   $ python examples/basic_usage.py

4. View Logs:
   $ docker-compose logs -f api

5. Run Tests:
   $ docker-compose exec api pytest tests/ -v
